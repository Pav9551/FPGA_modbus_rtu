# Устранение периодического сброса платы: WDG_SW = 1

## Назначение

Инструкция фиксирует успешно выполненную настройку STM32F407 на плате с FPGA: переключение независимого сторожевого таймера IWDG с аппаратного запуска на программный.

Итоговое требование: после записи, сброса и повторного чтения параметр WDG_SW должен оставаться равным 1.

## Симптомы в проверенном случае

- На общей линии SYS_RSTN наблюдались низкие импульсы примерно каждые 33,5 секунды.
- После переключения STM32 на системный загрузчик период составлял около 0,5 секунды.
- Упрощение программы FPGA не устраняло импульсы.
- После изменения WDG_SW на 1 периодические сбросы прекратились — результат подтверждён проверкой пользователя.

Эти периоды описывают конкретный случай и не являются универсальным способом определения причины сброса.

## Значение параметра

| WDG_SW | Режим IWDG |
|---|---|
| 0 | Аппаратный запуск watchdog |
| 1 | Программный запуск watchdog |

WDG_SW = 1 не запрещает использование watchdog: программа STM32 по-прежнему может запустить его самостоятельно.

## Перед началом

1. Использовать STM32CubeProgrammer и исправное питание платы.
2. Сохранить скриншот текущих option bytes.
3. Если важна программа STM32, заранее обеспечить наличие её резервной копии или исходного файла прошивки.
4. Не выполнять Mass erase: для данной настройки стирание пользовательской Flash не требуется.
5. Не менять RDP, защиту секторов и остальные option bytes.

## Подключение через UART

1. Выключить питание платы.
2. Установить BOOT0 = 1, BOOT1 = 0 на разъёме выбора загрузки P3.
3. Подключить USB-разъём платы, связанный с CH340, и включить питание.
4. Закрыть терминалы и другие программы, использующие COM-порт платы.
5. В STM32CubeProgrammer выбрать UART и COM-порт CH340.
6. Установить параметры: 115200 бод, 8 бит данных, Even parity, 1 стоп-бит, без управления потоком.
7. Нажать Connect.

Если UART-соединение нестабильно из-за сбросов, использовать ST-Link по SWD с подключённым NRST и режимом Under Reset / Hardware reset. Не записывать настройки по постоянно обрывающемуся соединению.

## Чтение текущего значения

1. Открыть OB / Option Bytes.
2. Нажать Read, не изменяя поля.
3. Найти WDG_SW и проверить считанное значение.

Read считывает настройки из STM32. Установка галочки и последующее нажатие Read не записывают выбранное значение: чтение обновляет отображение из устройства.

В проверенном случае по адресу 0x1FFFC000 было прочитано слово 0x55E0AA1F. Бит 5 младшего байта 0x1F равен 0, что соответствовало аппаратному запуску IWDG. Не использовать это слово как универсальный шаблон настроек другой платы.

## Изменение WDG_SW

1. Во вкладке Option Bytes установить только WDG_SW = 1, то есть Software watchdog.
2. Убедиться, что остальные поля не изменены.
3. Нажать Apply.
4. Дождаться успешного завершения записи. Не отключать питание во время операции.
5. После завершения выполнить системный сброс или выключить и снова включить питание.

Не редактировать целое слово option bytes вручную через окно памяти: изменять только именованное поле WDG_SW.

## Обязательная проверка сохранения

1. Повторно подключиться к STM32CubeProgrammer.
2. Открыть Option Bytes и нажать Read.
3. Убедиться, что WDG_SW остался равным 1.
4. Если STM32 должен запускать пользовательскую программу, при выключенном питании вернуть BOOT0 = 0 и восстановить штатное положение остальных перемычек.
5. Включить плату и проверить SYS_RSTN анализатором не менее минуты.

Критерии успеха:

- WDG_SW = 1 после повторного чтения и перезапуска питания.
- Периодические низкие импульсы SYS_RSTN, вызванные аппаратным watchdog, отсутствуют.
- Кнопка сброса продолжает выполнять штатную функцию.

Если импульсы сохраняются при WDG_SW = 1, требуется отдельная диагностика: сама настройка не исключает программный запуск IWDG и другие источники сброса.

## Важные предупреждения

- Mass erase не является необходимым шагом этой процедуры.
- Если пользовательская Flash STM32 уже стёрта, изменение WDG_SW не восстановит прежнюю программу: её потребуется загрузить отдельно.
- Не менять RDP ради устранения watchdog и не выполнять сброс всех option bytes к заводским значениям.
- При ошибке Apply сохранить журнал и проверить подключение, а не повторять стирание Flash.
